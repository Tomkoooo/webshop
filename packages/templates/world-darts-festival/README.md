# World Darts Festival

Festival landing template (World Masters / WDF style) with tBook ticket booking, CMS navigation with dropdowns, and organizer contact form.

- **Home** — hero, schedule, venue, fees, sponsors, contact (`/admin/cms/home`)
- **Booking** — `/jegyek`, `/foglalas/[eventId]` (requires `t-book` plugin + API key in CMS)
- **Domains** — e.g. `worlddartsfestival.com` (customer site); tBook admin on separate host
